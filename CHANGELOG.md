# Changelog

## 2.0.0

- Renamed the plugin to Folder Palette.
- Added Catppuccin Mocha, Nord, Monokai, and editable custom palettes.
- Added visible-order and stable path assignment modes.
- Added inherited, uncolored, and independent file-color modes.
- Added folder-block, individual-row, and continuous grouping modes.
- Added complete appearance controls and searchable folder overrides.
- Added automated tests, production builds, CI, and GitHub release automation.
